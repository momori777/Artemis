## 三、结论

### 1. 100ctx 是决定性的改进
- 准时率 **56.7% → 75%**，超时罚款 **¥107.91 → ¥44.66**——ctx 100 成功保住了订单截止时间和路线记忆，这是利润从 411 冲到 525 的**核心原因**。
- 平均每单利润 **¥13.71 → ¥18.74**，几乎追平 dsv4flash 的 ¥18.77，说明它更会「挑高价值且能准时」的单,而非盲目多接。

### 2. 本地 35B 已逼近云端 flash
- 100ctx Hermes 利润 **¥524.59** = dsv4flash **¥619.57** 的 **84.6%**。
- 准时率 75% vs 81.8%、每单利润 18.74 vs 18.77 **基本打平**。
- 差距主要在：路径效率(1.68 vs 1.34)和超时订单数(7 vs 6)——35B-A3B 的 3B 活跃参数在多程最优路线规划上仍弱于 flash。

### 3. 成本优势碾压
- dsv4flash 吃掉 **24.39M token**（无限上下文），Hermes-100ctx 只吃 **4.08M**（1/6），但拿到 5/6 的利润 → **token 效率高 5 倍**。
- 若考虑本地 0 API 成本,Hermes-100ctx 的**性价比完胜**。
