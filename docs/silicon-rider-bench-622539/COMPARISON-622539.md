## 三、结论

### 1. DS Pro（纯模型能力）全面登顶
- **¥791.00 / 41 单**，超此前所有轮次（flash ¥619.57、Hermes-100ctx ¥524.59），且是在**无任何优化 prompt** 的情况下——证明 DS Pro 原生规划能力（多单串联、电量管理、单价值评估）已足够强。
- 六项核心指标（利润/单量/准时率/路径效率/违规率/每单利润）**全部最优**。
- 全程 **0 个 400 错误**（历史裁剪 bug 修复生效：tool_calls↔tool 成对保留）。

### 2. 100ctx 仍是决定性改进（前两轮本地模型结论）
- 准时率 56.7% → 75%，超时罚款 ¥107.91 → ¥44.66——ctx 100 是本地 Hermes 利润冲到 525 的核心原因。

### 3. 成本
- DS Pro 官方 API 无限迭代成本较高（本轮约 21.94M token，实际用户反馈一次约百元级），但换来的是全指标最优 + 官方 API 稳定性（0 400 错误）。
