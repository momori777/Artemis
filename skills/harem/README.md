# harem — 后宫角色存档 / Harem Character Archive

## 中文

后宫角色存档目录，每个角色一个子目录（SOUL.md + IDENTITY.md）。由 `character_importer` 管理切换。

- **SOUL.json** — 后宫角色索引
- 每个子目录 = 一个可切换角色

## English

Harem character archive; one subdirectory per character (SOUL.md + IDENTITY.md). Managed/switched by `character_importer`.

- **SOUL.json** — harem character index
- Each subdirectory = one switchable character
