# tool — 工具模式提示词包 / Tool-Mode Prompt Bundle

## 中文

OpenClaw 工具模式（非角色扮演）的提示词文件集合，由 `character_importer` 在角色切换时启用/恢复。

| 文件 | 说明 |
|------|------|
| `AGENTS.md` | 工具模式主 AGENTS（英文） |
| `AGENTS_CN.md` / `AGENTS_EN.md` / `AGENTS_JA.md` | 各语言版 AGENTS |
| `AGENTS_roleplay_full_*.md` | 完整角色扮演模式 AGENTS（CN/EN/JA） |
| `AGENTS_roleplay_lite_*.md` | 精简角色扮演模式 AGENTS（CN/EN/JA） |
| `AGENTS.md.roleplay.bak` / `AGENTS_roleplay_full_CN.md.bak` 等 | 切换前备份 |
| `IDENTITY.md` / `IDENTITY_CN.md` | 工具模式身份 |
| `SOUL.md` / `SOUL_CN.md` | 工具模式 SOUL |
| `output-skill.md` | 输出完整性规范（禁止截断/骨架代码） |

## English

Prompt files for OpenClaw tool mode (non-roleplay), enabled/restored by `character_importer` on character switch.

| File | Description |
|------|-------------|
| `AGENTS.md` | Tool-mode main AGENTS (English) |
| `AGENTS_CN.md` / `AGENTS_EN.md` / `AGENTS_JA.md` | Localized AGENTS variants |
| `AGENTS_roleplay_full_*.md` | Full roleplay-mode AGENTS (CN/EN/JA) |
| `AGENTS_roleplay_lite_*.md` | Lite roleplay-mode AGENTS (CN/EN/JA) |
| `AGENTS.md.roleplay.bak` etc. | Pre-switch backups |
| `IDENTITY.md` / `IDENTITY_CN.md` | Tool-mode identity |
| `SOUL.md` / `SOUL_CN.md` | Tool-mode SOUL |
| `output-skill.md` | Output integrity rules (no truncation/skeleton code) |
